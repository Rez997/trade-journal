# ژورنال ترید

ژورنال شخصی برای ثبت ترید‌های فارکس: نماد، تایم‌فریم، ستاپ، قیمت‌ها و R، چک‌لیست انضباط، حس هنگام ورود، عکس قبل و بعد از ترید، و داشبورد آماری.

- بدون سرور و بدون نصب؛ فقط HTML و JavaScript
- قابل نصب مثل اپ (PWA) روی لپ‌تاپ و گوشی، و کار بدون اینترنت
- داده‌ها و عکس‌ها فقط روی همان دستگاه (IndexedDB) ذخیره می‌شوند و به هیچ سروری فرستاده نمی‌شوند

## انتشار روی GitHub Pages

1. در GitHub یک ریپازیتوری جدید بساز (مثلاً `trade-journal`).
2. همه‌ی فایل‌های این پوشه را آپلود کن (Add file → Upload files).
3. در ریپازیتوری برو به **Settings → Pages**، بخش Source را روی **Deploy from a branch** بگذار، شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب کن و Save بزن.
4. بعد از یکی دو دقیقه برنامه در این آدرس باز می‌شود:
   `https://<نام-کاربری>.github.io/trade-journal/`

## نصب مثل اپ

در Chrome یا Edge آدرس بالا را باز کن و روی آیکون نصب در نوار آدرس بزن (یا منو → Install). از آن به بعد مثل یک برنامه‌ی جدا از منوی استارت باز می‌شود.

## اجرا بدون GitHub (فقط روی لپ‌تاپ)

در همین پوشه:

```
python -m http.server 8000
```

و بعد `http://localhost:8000` را باز کن.

## نکته‌های مهم

- داده‌ها برای هر مرورگر و دستگاه جداست. ترید‌های لپ‌تاپ خودبه‌خود روی گوشی نمی‌آیند.
- با دکمه‌ی **دانلود پشتیبان** پایین صفحه، از همه‌ی ترید‌ها و عکس‌ها یک فایل JSON بگیر. با **بازگردانی پشتیبان** همان فایل را روی دستگاه دیگر یا بعد از پاک شدن مرورگر برگردان.
- پاک کردن داده‌های سایت در مرورگر، ژورنال را هم پاک می‌کند؛ پس پشتیبان منظم بگیر.
- اگر ریپازیتوری Public باشد، فقط **کد** عمومی است؛ ترید‌هایت هرگز داخل ریپازیتوری نمی‌روند.

## ساختار فایل‌ها

| فایل | کار |
|---|---|
| `index.html` | کل برنامه |
| `manifest.webmanifest` | اطلاعات نصب مثل اپ |
| `sw.js` | کش برای کار بدون اینترنت |
| `icon.svg`, `icon-192.png`, `icon-512.png` | آیکون‌ها |
